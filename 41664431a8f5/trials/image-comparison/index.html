Image comparison

View as MarkdownOpen in ClaudeOpen in ChatGPT

Images are compared with Scion.Compare: a per-pixel perceptual distance (OKLab with the HyAB metric), a tolerance per recipe (ImageTolerance), masks for regions that must be ignored, and an optional mask learned from runs that shows which pixels are unstable. The result is a status per artifact (Same, Within, Changed), a changed ratio, the bounds of the change and a heatmap diff.png.

When to use

Section titled “When to use”
  • Keep the default tolerance for most recipes: it ignores dithering and GPU rounding and catches visible changes.
  • Use ImageTolerance.Exact for pixel art and UI that must not move a pixel.
  • Set Tolerance = null for recipes where only the rules matter: images are captured but never compared.

2. Mask what changes on purpose

Section titled “2. Mask what changes on purpose”

Coordinates are normalized (0 to 1) with the origin at the bottom left, like Screen. At run time, session.MaskRect(screenPixels, why) adds a mask in pixels.

3. Learn unstable pixels

Section titled “3. Learn unstable pixels”

The recipe runs 3 times; pixels that differ between those runs form unstable.png, saved with the baseline when approved. A learned mask may cover at most 2 % of the image: above that, the recipe is not deterministic enough to mask, and the run warns mask_cap instead of hiding the problem.

The metric

Section titled “The metric”

Each pixel pair is converted to OKLab and compared with HyAB (absolute lightness difference plus Euclidean distance in a and b), scaled to 0 to 1. A pixel counts as changed when its distance is above Pixel. The image is:

Status When
Same No changed pixel.
Within Changed pixels are at most MaxRatio of the unmasked area and at most MaxPixels (when not -1).
Changed Otherwise.

The same metric gives the same result on every machine, so baselines from one Mac compare with captures from another Mac of the same platform id.

Tolerances

Section titled “Tolerances”
Value Pixel MaxRatio MaxPixels
ImageTolerance.Default 0.1 0.001 -1
ImageTolerance.Exact 0 0 0
null (recipe) images not compared; frame hash changes give px_changed

Outputs

Section titled “Outputs”
File Content
<run>/diff/<IdDir>/r<n>/<artifact>.diff.png Heatmap: changed pixels in red over a grey copy of the current image; masks hatched.
compare.json Per id: verdict, reasons, image statuses, ratios, bounds (pixels, top-left origin) and diff paths.
trial show --grid output Baseline, current and diff side by side.

Errors

Section titled “Errors”
Code Exit Cause Next action
warning mask_cap 0 The learned mask would cover more than 2 %. Make the recipe deterministic (Particles, animators, UI and physics).
warning px_unstable 0 Frame hashes vary between rounds of this run. Same as above; px_changed is noise until fixed.
warning baseline_unreadable 0 A baseline image or JSON cannot be read. Check Git LFS (git lfs pull).
