Write an adapter

View as MarkdownOpen in ClaudeOpen in ChatGPT

The adapter is the game’s only Trials-specific code: it prepares the game once, plays each recipe (load, set up, act, wait), cleans up and reports a hash of the rules state. Derive from TrialAdapter<TRecipe> and register it with [assembly: TrialAdapter(typeof(...))]. This guide covers Prepare, Run, Teardown, StateHash, how a recipe picks its adapter, the coroutine rules, and the reset and seeding every adapter must do. Errors: SCN202, SCN203.

When to use

Section titled “When to use”
  • Write one adapter per family of recipes that start the same way: battles, HUD screens, menus.
  • Use ITrialAdapter directly only when the choice depends on something other than the recipe’s type.
  • For screens and items that need no action, derive recipes from StaticTrial<TItem> and skip the adapter entirely (Static trials).

2. Reset global state between recipes

Section titled “2. Reset global state between recipes”

Every recipe must start from the same state, whatever ran before it in the queue:

  • end and unload what Run created in Teardown;
  • reset statics and singletons the game keeps (Time.timeScale, caches, pools) in Teardown or on TrialSession.Boundary;
  • seed every random source from the recipe: UnityEngine.Random and new System.Random() are seeded by the session; seed the game’s own generators from s.RunSeed and the recipe’s Seed.

3. Run it twice

Section titled “3. Run it twice”

With two rounds, the determinism check fails any recipe whose StateHash differs between rounds.

Members

Section titled “Members”
Member Default Called
public virtual IEnumerator Prepare(TrialSession s) nothing Once per process, before the first recipe this adapter gets. With warm copies, at startup.
protected abstract IEnumerator Run(TRecipe r, TrialSession s) Per (recipe, round): set up, act, cut, probe.
protected virtual IEnumerator Teardown(TRecipe r, TrialSession s) nothing After Run, even when it failed.
public virtual string StateHash { get; } null Read after Run, before Teardown. A deterministic hash of the rules state, or null.

TrialAdapter<TRecipe> is a MonoBehaviour: the session gives it its own GameObject that survives scene loads. A plain ITrialAdapter (with Accepts) needs a public parameterless constructor.

Which adapter plays a recipe

Section titled “Which adapter plays a recipe”
  1. Only adapters whose recipe type is the recipe’s class or a base of it, and whose Accepts(recipe) is true, count. A plain ITrialAdapter handles TrialRecipe, the least specific type.
  2. The adapter with the most derived recipe type wins. TrialAdapter<HudStates> beats the package’s StaticTrialAdapter : TrialAdapter<StaticTrial> for HudStates.
  3. Two adapters for the same type are SCN203. Registration order decides nothing.

A selected recipe no adapter accepts fails alone, naming the registered adapters.

Coroutine rules

Section titled “Coroutine rules”
  • Everything is a coroutine: wait with yield return s.WaitUntil(...), s.WaitSeconds(...) or null, never with sleeps.
  • A throw, a timeout or s.Fail in Run fails the current recipe and stops Run at its next yield; Teardown still runs (limit 15 game seconds).
  • In Prepare, any of them stops the queue with exit 3 (prepare_failed). Prepare has a limit of 60 seconds of real time.
  • Split steps into methods and yield return Step(); so the guards reach them. A coroutine started with StartCoroutine runs outside the guards.

What makes a good StateHash

Section titled “What makes a good StateHash”
  • Only rules state: unit positions, HP, turn, RNG state of the core. Never presentation (animations, particles).
  • Stable across machines: integers, ordered collections, no GetHashCode of strings.
  • The same value the multiverse and co-op telemetry use, so one function serves all three.

Errors

Section titled “Errors”
Code Exit Cause Next action
SCN202 3 A registered type is not a valid adapter. Derive from TrialAdapter<TRecipe> with a public parameterless constructor.
SCN203 3 Two adapters handle the same recipe type. Keep one per type; make one more specific.
no_adapter 3 No [assembly: TrialAdapter] in the build. Register the adapter; dotnet scion diagnose writes a skeleton.
prepare_failed 3 Prepare threw, timed out or called Fail. Read player.log of the copy.
