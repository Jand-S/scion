# Metamorphic tests

A metamorphic test checks a relation between two runs instead of one expected value: mirroring the map must
mirror the result, swapping players must swap the result, turning visual effects off must not change the hash,
saving and loading mid-match must not change the hash. Scion runs them on the core simulator in plain .NET, over
many seeds, so they find rule bugs no single recipe would.

## When to use

- On every rule change, in CI: they are fast and need no Unity.
- When adding a mechanic with symmetry (positions, teams, turn order).

## Before you begin

- Adoption level 3 (`ISimulation` registered).
- The state implements the interface each property needs: `IMirrorable`, `IPermutable`, `ISaveable`.

## Steps

### 1. Declare the properties in a spec

```csharp
public sealed class RulesHold : TrialSpec
{
    public override string Name => "RulesHold";
    public override string Target => "Orchard's rules are symmetric and save-safe.";

    public override void Define(SpecBuilder s)
    {
        s.Metamorphic(Metamorphic.Mirror, matches: 200);
        s.Metamorphic(Metamorphic.Permute, matches: 200, players: 4);
        s.Metamorphic(Metamorphic.VisualToggle, matches: 50);
        s.Metamorphic(Metamorphic.SaveLoad, matches: 200);
    }
}
```

### 2. Run

```sh
dotnet scion trial run --spec RulesHold
```

A failure names the property, the seed, the turn and the field:

```text
Mirror: seed 117, turn 5: units[2].x is 3, mirrored run has 5 (expected 4)
```

### 3. Turn a failure into a recipe

```sh
dotnet scion hunt run RulesHold --seed 117 --save
```

saves the failing match to `scion/recipes/found/`.

## Reference

| Property | Relation | State needs |
|---|---|---|
| `Metamorphic.Mirror` | Run on the mirrored map; the final state equals the mirror of the original's. | `IMirrorable.Mirror()` |
| `Metamorphic.Permute` | Swap player seats; the result is permuted the same way. | `IPermutable.Permute(int[] order)` |
| `Metamorphic.VisualToggle` | Run in the test build with every promoted graft disabled; the hash is the same. | a test build |
| `Metamorphic.SaveLoad` | Save at a random turn, load, continue; the hash is the same. | `ISaveable.Save()`, `Load(byte[])` |

Matches are generated by bots from seeds 1 to `matches`. `VisualToggle` runs the recipes in the test build instead of
the simulator.

## Errors

| Code | Exit | Cause | Next action |
|---|---|---|---|
| `no_simulation` | 3 | No `ISimulation`. | Register one ([Core API](/scion/reference/api/core/)). |
| spec `ok: false` | 1 | A property failed. | Read the seed, turn and field; save the match. |

## Examples

### Only save-load, many seeds

```csharp
s.Metamorphic(Metamorphic.SaveLoad, matches: 5000);
```

### A custom property

```csharp
s.Metamorphic("heal_then_hit_equals_hit_then_heal", (sim, seed) => HealOrder.Check(sim, seed), matches: 300);
```
