Scion

Graft new code onto a Unity game, test it in the real build, judge the result. Built for AI agents.
Get startedFor AI agents

Scion 1.0.0 is a Unity 6 package (me.jandson.scion) and a .NET command line (dotnet scion). Your game stays the trunk; new code arrives as small branches grafted onto it at compile time, and every change is played, captured and compared in the real player build before it ships.

Grafts

Section titled “Grafts”

Static C# methods marked [Before] or [After] hang onto existing game methods, woven into the IL at compile time. Final builds call them directly; test builds swap them live in about a second. How grafts work.

Trials

Section titled “Trials”

Deterministic recipes play in parallel copies of the real test player, headless, on a virtual clock. Each run records a state hash, frames and images, runs checks and compares everything with approved baselines. How trials work.

Judge

Section titled “Judge”

Frozen vision models turn every capture into numbers once; small heads trained in seconds on your own votes rank results by taste. The Judge filters and orders; a person always makes the final choice. The Judge.

Exploration

Section titled “Exploration”

Fork a deterministic match at any turn, loop a moment of play while you tune it, bisect regressions, hunt rare states and search tunables with guided duels. The multiverse.
