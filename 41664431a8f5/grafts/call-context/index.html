Call and Call<T>

View as MarkdownOpen in ClaudeOpen in ChatGPT

A graft may take one extra parameter, always the last, that gives it the per-call context: ref Call for targets that return void, ref Call<T> for targets that return T. With it a graft reads Skipped, skips the target with Skip(), returns early with Return(value), reads or replaces the result through Result, and hands state from a [Before] to an [After] of the same call with Tag. The weaver checks the rules as SCN108, SCN109 and SCN111.

When to use

Section titled “When to use”
  • Use Skip() or Return() to suppress or replace presentation: skip a banner during a replay, cut an animation short, return a shorter duration.
  • Use Result in an [After] to adjust what the target returns (a duration, a color, a position).
  • Use Tag to measure or correlate something between the start and the end of one call.
  • Do not use any of these to change rules. Skipping a rule method in a graft desynchronizes co-op peers; the analyzer reports writes to rule state as SCN003.

Steps

Section titled “Steps”

1. Declare the context as the last parameter

Section titled “1. Declare the context as the last parameter”
Target returns Last parameter Members
void ref Call c Skipped, Skip(), Tag
T ref Call<T> c, with T equal to the return type Skipped, Result, Return(T), Tag

It must be passed by ref; a Call by value, in or out is a signature error (SCN104). A T that differs from the return type, or Call on a target that returns a value, is SCN109.

In an [After], Result is what the target returns now, and the graft may change it; the next after sees the changed value. In a [Before], Result is the value returned if the target is skipped.

Reference

Section titled “Reference”

Order in one call

Section titled “Order in one call”
Step Who runs Can skip
1 Observers ([Before(..., Observe = true)]), by Priority no
2 Other befores, by Priority; the first that skips stops the rest of this step and step 3 yes
3 The target’s body
4 Afters, by Priority, with Skipped set if step 2 skipped no

If the body throws, step 4 does not run. The context lives on the anchor’s stack: nothing allocates.

Members

Section titled “Members”
Member Call Call<T> Meaning
Skipped yes yes True after a before skipped the call.
Skip() yes Skip the rest of the befores and the body. Non-observer befores only (SCN108).
Result yes After: the current return value, settable. Before: the value returned on skip.
Return(T value) yes Result = value and skip. Non-observer befores only (SCN108).
Tag yes yes A long shared by every graft of one call; 0 at the start.
Call(T result) constructor yes For tests outside Unity: a context that holds a result.

Cost

Section titled “Cost”

Measured on an Apple M5: in IL2CPP call mode, a graft without context adds nothing measurable, a [Before] with ref Call adds about 0.5 ns and an [After] with ref Call<float> about 0.2 ns. In Mono slot mode (test builds), the same cases cost about 2 to 7 ns; prefer int over float results in hot paths of test builds.

Errors

Section titled “Errors”
Code Exit Cause Next action
SCN104 compile error Call not passed by ref, or not the last parameter. ref Call c or ref Call<T> c, last.
SCN108 compile error Skip() or Return() in an [After] or an observer. Use a non-observer [Before], or only read c.Skipped.
SCN109 compile error Call<T> with the wrong T, or Call on a non-void target. Match the target’s return type.
SCN111 compile warning Several befores or afters of one anchor use Tag. Let one graft own Tag.
