Write a graft

View as MarkdownOpen in ClaudeOpen in ChatGPT

This guide writes grafts with [Before(typeof(T), "Method")] and [After(typeof(T), "Method")]: the method shape the weaver accepts (static void, public or internal, not generic, SCN101), the folder with an .asmref that compiles it into the target’s assembly (SCN102), how parameters bind to the target (exact signature, then a unique prefix, SCN112), and the ordering controls Priority and Observe.

When to use

Section titled “When to use”
  • Use a graft to add presentation to a game method without editing it: an effect, a sound, a camera move, a HUD change, telemetry, a trials mark.
  • Do not use a graft to change a rule (damage, range, turn order, anything in the state hash). Change the core with a RuleModifier<T> (Grafts are visual only).

Section titled “Before you begin”
  • The game assembly references Scion.Runtime (dotnet scion init adds it).

Reference

Before and After

Section titled “Before and After”
Attribute Runs Typical use
[Before(typeof(T), "Method")] before the target’s body watch a call, guard it, skip it, return early
[After(typeof(T), "Method")] at every return of the target react to a call, read or change its result

Name the target with nameof when it is visible from the graft, and with a string when it is private:

Both attributes allow multiple use, so one method can hang on several targets. Targets must be declared on the type itself: a method inherited from a base class is not found (SCN103).

Method shape

Section titled “Method shape”
Rule Diagnostic
static void SCN101
public or internal (injected drafts: public, in a public type) SCN101
Not generic, not in a generic type, not in a private or protected nested type SCN101
Compiled into the target’s assembly (folder with an .asmref) SCN102
Never called by game code SCN110

Name the class after the graft (CritShake) and the method after its side (Before or After). The graft’s identity is its full name, Orchard.Grafts.CritShake.After: it orders ties, names the graft in Fx telemetry and decides which promoted graft an injected one replaces.

Parameter binding

Section titled “Parameter binding”

A graft’s parameters mirror the target’s:

  1. the target instance, for instance methods (omit it for static targets);
  2. the target’s parameters, in order, with the same in and ref modifiers;
  3. optionally, last, ref Call (void target) or ref Call<T> (target returns T).

Prefixes. A graft may stop early and declare only the first parameters:

Overloads. The overload whose full signature matches wins; otherwise the single overload the prefix matches. When a prefix matches two or more overloads, it is SCN112: declare all parameters. A signature that matches nothing is SCN104, whose hint gives the expected signature.

Values. A graft sees the current parameter values: if the body reassigns a parameter, an [After] sees the new value.

Overrides. On a virtual method, a graft fires only for the method it targets. A graft on UnitView.Play does not fire when an override in KnightView runs without calling base.Play: target the override.

Priority

Section titled “Priority”

Priority (an int, default 0) orders the grafts of one anchor and side: lower runs first. Ties break on the graft’s full name (ordinal), so order never depends on file or compile order.

Observe

Section titled “Observe”

Observe = true (only on [Before]) marks an observer: a graft that only watches. Observers always run, before every [Before] that may skip the target, ordered by Priority among themselves, and may not call Skip() or Return() (SCN108). Use one when the graft must see every call, including calls another graft skips, such as a trials mark. Order within one call

Section titled “Order within one call”
  1. observers, by Priority;
  2. the other [Before] grafts, by Priority; the first that skips stops the remaining befores and the body;
  3. the target’s body;
  4. the [After] grafts, by Priority; they also run after a skip, and can read Skipped.

If the target throws, the [After] grafts do not run.

Errors

Section titled “Errors”
Code Exit Cause Next action
SCN101 compile error Not static void, private, generic, or in a generic or hidden type. public static void After(...) in a non-generic public class.
SCN102 compile error The file compiles into another assembly than the target. Move it to the folder with the .asmref.
SCN103 compile error The target method does not exist on that type. Use the name from the hint.
SCN104 compile error Parameters match no overload. Copy the expected signature from the hint.
SCN105 compile error The target cannot be an anchor. Hang the graft on the plain method it calls.
SCN108 compile error Skip or Return in an [After] or an observer. Move it to a non-observer [Before].
SCN112 compile error A prefix matches several overloads. Declare all parameters.

In graft check and build test these come back in diagnostics[] or errors[] with exit code 1. The full list is in Graft diagnostics.
